📄 关键文件职责说明

1. game.py (胶水层)

这是最重要的文件，负责依赖注入，确保所有系统都能互相访问，且没有循环导入。
# game.py
from core.state import Player
from core.events import EventBus
from systems.battle import BattleSystem
from systems.map import MapSystem
from systems.loot import LootSystem
from systems.level_up import LevelUpSystem
from systems.relics import RelicManager
from utils.excel_loader import ExcelLoader

class GameContext:
    def __init__(self):
        # 数据
        self.loader = ExcelLoader("data/game_data.xlsx")
        self.state = Player()
        self.bus = EventBus()
        
        # 子系统 (注入 self)
        self.battle = BattleSystem(self)
        self.map = MapSystem(self)
        self.loot = LootSystem(self)
        self.level_up = LevelUpSystem(self)
        self.relics = RelicManager(self)
        
        # 初始化
        self._init_player_stats()

    def _init_player_stats(self):
        # 从 Excel 的 Stats 表读取初始属性
        base_stats = self.loader.stats['Base']
        self.state.stats = base_stats.copy()

# systems/battle.py
class BattleSystem:
    def __init__(self, ctx):
        self.ctx = ctx

    def resolve(self, attacker, defender, card):
        # 1. 判定 (d20 + STR vs DEX)
        to_hit = DiceRoller.attack_roll(
            attacker.stats['STR'], 
            defender.stats['DEX']
        )
        
        if to_hit < defender.ac: # AC 由 DEX 决定
            return "Miss"
        
        # 2. 结算 (3d6 + STR)
        dmg = DiceRoller.damage_roll(card['Damage'], attacker.stats['STR'])
        
        # 3. 应用遗物效果
        self.ctx.relics.on_damage_dealt(attacker, defender, dmg)
        
        defender.hp -= dmg

5. main.py (主循环)

# main.py
import curses
from game import GameContext
from ui.renderer import AsciiRenderer
from ui.input_handler import InputHandler

def main(stdscr):
    ctx = GameContext()
    renderer = AsciiRenderer(stdscr)
    input_handler = InputHandler(ctx)
    
    while True:
        # 根据 ctx.map.current_node 决定渲染哪个界面
        if ctx.map.is_battle:
            renderer.render_battle(ctx)
        elif ctx.map.is_loot:
            renderer.render_loot(ctx)
        # ...
        
        key = stdscr.getch()
        input_handler.handle(key)

if __name__ == "__main__":
    curses.wrapper(main)


📊 Excel 结构回顾 (最终版)

Sheet名 关键列 作用

Cards ID, Name, DeckType(Player/Encounter/Neutral), Cost, Check(d20+STR), Damage(2d6+STR), Keywords 所有卡牌/遗物数据

Enemies ID, Name, HP, Stats(STR/DEX/VIT), Deck(关联Cards) 敌人数据与他们的牌库

Stats StatID, Name, BaseValue 属性定义

Events ID, Type(Rest/Shop/Boss), Options 地图节点事件

✅ 架构优势总结

1.  高内聚：core 纯逻辑，systems 纯业务，ui 纯表现。  
2.  无循环依赖：game.py 作为中心枢纽，所有子系统只依赖 GameContext。  
3.  数据驱动：除了 config.py，没有任何硬编码的数值或文本。  
4.  易于测试：BattleSystem 可以脱离 UI 直接进行单元测试（传入假数据）。  
5.  魂味十足：d20 + 属性 的判定让升级属性变得极其有意义。
