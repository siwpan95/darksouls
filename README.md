## 语言 / 类型
- Python / pygame 图形界面卡牌游戏（Roguelike）

## 目录要点
- `main.pyw` —— 入口（`python main.py`）
- `game/`、`screens/`、`controllers/`、`models/`、`services/` —— 游戏主体
- `data/`、`assets/`、`tests/` —— 数据、资源与测试
- `architecture.md`、`prd.md` —— 架构与需求设计文档

## 运行方式与依赖
- 运行：`python main.pyw`
